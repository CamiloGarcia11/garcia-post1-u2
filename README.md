## Descripción
Post-contenido de la Unidad 2 de Patrones de Diseño de Software. Proyecto Maven único (`exportador-reportes/`) que resuelve la exportación de actas de calificaciones en múltiples formatos coherentes (PDF, Excel, HTML) aplicando el patrón Abstract Factory con registro dinámico desacoplado (Parte 1), y se extiende mediante una configuración flexible e inmutable usando el patrón Builder y la evaluación objetiva sobre la necesidad de Singleton (Parte 2).
